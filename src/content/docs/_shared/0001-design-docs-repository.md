## 背景 / 課題

設計判断が各リポジトリや外部サービスに分散すると、決定の理由と変更の経緯をあとから辿れません。

## 決定

設計ドキュメントを専用の Git リポジトリに集約し、Markdown のままレビューして静的サイトとして公開します。

## 影響範囲

個別の実装リポジトリから対象ドキュメントへリンクを張り、実装と判断の対応を明示します。
